# Web Ulang Tahun Interaktif (Ifa Anisahtul Framesti - 22nd Birthday) 🌸✨

Website ulang tahun interaktif bertema **Cute & Clean Canvas Scrapbook** dengan perpaduan warna **Soft Pastel Pink** dan **Sky Blue**, animasi transisi GSAP + ScrollTrigger, 3D Polaroid card tilt, pemutar musik piano akustik emosional, serta fitur tiup lilin interaktif.

## 🚀 Fitur Utama
- **Opening Splash Screen**: Layar pembuka kejutan ulang tahun interaktif.
- **5 Photo Story Chapters**: Narasi cerita dari 5 momen foto Polaroid dengan efek parallax & drop animation.
- **Interactive Birthday Cake 🎂**: 22 lilin yang dapat ditiup/diklik dengan letupan kembang api & *confetti*.
- **Emotional Piano Synthesizer 🎵**: Pemutar musik piano akustik emosional & penuh semangat.
- **Wish Box 💌**: Papan ucapan & doa interaktif.

## 📁 Struktur File
- `index.html` - Layout utama website
- `styles.css` - Stylesheet, warna pink & sky blue, animasi CSS
- `script.js` - Logika interaksi canvas, GSAP animations, Web Audio API synth
- `foto1.jpeg` s/d `foto5.jpeg` - Galeri foto utama

Crafted with 💕 for **Ifa Anisahtul Framesti**'s 22nd Birthday Celebration.
